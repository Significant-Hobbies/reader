# Reader

Reader is a saved-link inbox. Paste a URL or save the current tab with the Chrome extension. Connect ChatGPT through MCP to find links, retrieve available source text, and mark them read or unread when you ask.

The web app has a link list, an add-link action, and Connections. There is no RSS, built-in AI, article reader, annotation, board, memory, or PDF-capture workflow.

Google sign-in identifies the account. Links and MCP tool results are private. Fetching a source does not mark it read. A site may block extraction; its original URL remains available.

The Chrome extension is source-built for unpacked use; public distribution is deferred. There is no public plan or checkout.
