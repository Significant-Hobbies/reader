# Features

The active product scope is defined in [overview.md](overview.md).

- URL capture in the app and Chrome extension.
- Read/unread/all inbox, title/URL search, and pagination.
- Explicit read/unread updates in the app or ChatGPT.
- MCP search, source-text retrieval, and read-state updates.
- Account isolation and revocable extension keys.

Source implementation does not establish live rollout. See [project status](../../PROJECT_STATUS.md).
